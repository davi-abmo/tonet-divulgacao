# TONET

> **O melhor amigo de qualquer artista.**

O TONET é uma proposta de plataforma voltada para artistas, público e empresas, com o objetivo de facilitar a divulgação de trabalhos, a descoberta de novos talentos, a interação entre artistas e a criação de novas oportunidades.

## 📌 Sobre o projeto

A ideia do TONET surgiu a partir de relatos de artistas sobre dificuldades para divulgar seus trabalhos, encontrar clientes e encontrar oportunidades relacionadas às suas áreas de atuação.

A proposta é criar uma plataforma que reúna **comunidade, portfólios, divulgação e oportunidades** em um único ambiente.

O projeto ainda está em desenvolvimento e, neste momento, este repositório contém o **site de divulgação do TONET**, utilizado para apresentar a proposta, funcionalidades e equipe do projeto.

## 🎯 Objetivos

* Facilitar a divulgação do trabalho de artistas;
* Ajudar usuários a descobrir novos artistas;
* Facilitar a conexão entre artistas e empresas;
* Permitir a criação de portfólios personalizados;
* Criar um ambiente voltado para a comunidade artística;
* Facilitar o surgimento de colaborações e oportunidades.

## 👥 Tipos de usuário

A proposta atual do TONET contempla três principais tipos de usuários:

### Usuário comum

Pode descobrir artistas, visualizar portfólios, interagir com publicações e participar da comunidade.

### Artista

Pode criar um perfil artístico, apresentar seu portfólio, divulgar suas habilidades e buscar oportunidades.

### Empresa

Pode encontrar artistas, divulgar oportunidades e buscar profissionais para projetos e trabalhos.

## 🚀 Funcionalidades planejadas

Entre as funcionalidades previstas para a plataforma estão:

* Perfis de artistas;
* Portfólios personalizados;
* Publicações;
* Interação entre usuários;
* Categorias e tags;
* Comunidades;
* Busca por artistas;
* Oportunidades de trabalho;
* Contratação de artistas;
* Divulgação de portfólios;
* Anúncios pagos.
